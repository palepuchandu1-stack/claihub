# Product Company

A marketing/product showcase site built with TanStack Start, React 19, and Tailwind CSS 4, deployed on Netlify.

## Tech stack

- **TanStack Start** — full-stack React framework with file-based routing
- **React 19**
- **Vite 7** — build tooling
- **Tailwind CSS 4** — styling
- **Netlify** — hosting and deployment

## Running locally

```bash
pnpm install
pnpm dev
```

The dev server starts on `http://localhost:3000`.

## Build

```bash
pnpm build
```
